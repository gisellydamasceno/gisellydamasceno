## Data Science Projects

* ### Energy Consumption Forecasting
    Forecasting solution for the free energy market, predicting contract consumption to support risk management and commercial decisions. Built as a hybrid ensemble of a GRU network and LightGBM, with feature engineering (lags, cyclical features, seasonality), K-Means segmentation and prediction intervals to quantify uncertainty. Fully automated end-to-end pipeline on AWS with a quality gate and continuous monitoring.

* ### Document Data Extraction (NLP / OCR)
    Automated extraction of structured data from invoices using NLP and neural networks (InvoiceNet), deployed internationally across multiple languages and formats. Integrated with engineering systems through an event-driven architecture (RabbitMQ) and REST APIs, running on Kubernetes.

* ### Synthetic Data Generation
    Generation of synthetic data with GANs to enable analytics while preserving privacy, applying anonymization and privacy-by-design principles.

* ### Big Data Analytics with ELK Stack
    Dashboards and KPIs built on the ELK Stack (Elasticsearch, Kibana) to explore large volumes of data and enable self-service analytics for end users.
